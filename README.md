# Tic-Tac-Toe – VOSC Activity-1

## About the Project

This is a simple, interactive two-player Tic-Tac-Toe game created as part of VOSC Activity-1. Players take turns placing X and O on a 3 × 3 board, with wins and draws tracked on a scoreboard.

## Technologies Used

- HTML
- CSS
- JavaScript

No external libraries or frameworks are required.

## Features

- Two-player gameplay
- 3 × 3 clickable board
- Turn indication, with Player X starting first
- Detection of horizontal, vertical, and diagonal wins
- Draw detection
- Highlighting of the winning cells
- Scoreboard for Player X, Player O, and draws
- New Game button to start another round without resetting scores
- Responsive design with mobile support
- Accessible button controls and status announcements

## How to Run

Open `index.html` in a modern web browser. No installation, server, or dependencies are required. The game works offline.

## How to Play

1. Player X starts.
2. Click an empty cell to place your symbol.
3. Player O takes the next turn.
4. Players continue taking turns.
5. The first player to get three symbols in a row, column, or diagonal wins.
6. If all nine cells are filled without a winner, the round is a draw.
7. Click **New Game** to start another round. Scores stay visible until the page is refreshed.
